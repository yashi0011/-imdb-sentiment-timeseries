# IMDB Sentiment Time Series Analysis

## Overview
This project performs sentiment classification on IMDB movie reviews using machine learning and deep learning techniques (Logistic Regression, SVM, Naive Bayes, XGBoost, LSTM, and BERT). It also forecasts sentiment trends using ARIMA and Facebook Prophet.

## Files
- `imdb-sentiment-analysis-eda-ml-lstm-bert.ipynb` – Main Jupyter notebook
- `IMDB_Dataset_with_Timestamps.csv` – Dataset with synthetic timestamps
- `Final_Report.pdf` – Project report for submission

## Forecasting Models
- ARIMA
- Prophet
- Simple Exponential Smoothing (SES)

## Result
- BERT achieved ~90% sentiment classification accuracy
- Time series models forecast average monthly sentiment with good interpretability
